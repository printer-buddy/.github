# Security

## Reporting a problem

If you find a security problem in any Printer Buddy repository, please report it privately and do not open a public issue.

Open the repository on GitHub, go to the **Security** tab, and choose **Report a vulnerability**. Only the maintainers can see what you send.

Please include:

- what you found and which repository it is in
- the version (the installer and the dashboard both show it)
- the steps to reproduce it

## What to expect

We will read your report, confirm whether it is a real problem, and tell you what we plan to do. Please give us time to fix it before you share it publicly.

## Supported versions

Fixes go into the `nightly` branch first and then into the next stable release. Keep your install up to date with the Update option in the installer.
